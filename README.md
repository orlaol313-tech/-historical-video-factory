# BonnieAndOllieStudio

Бесплатная локальная студия мультсериала «Бонни и Оли». Платные API, подписки и кредиты не нужны.

## Как получить мультфильм (одна команда)

```bash
python3 scripts/build_episode.py episodes/episode_001
```

Готовое видео: `renders/episode_001.mp4` (60 с, 1920×1080, 16:9, 24 к/с, звук AAC).
Сборка занимает около минуты на 4 ядрах. Быстрая проба на 6 секунд: добавьте `--preview 6`.

Нужны: Python 3, пакеты `numpy`, `pillow`, `pyyaml`, программа `ffmpeg` и шрифт DejaVu Sans. Больше ничего устанавливать не нужно.

## Проверка готового файла

```bash
python3 scripts/verify_video.py renders/episode_001.mp4
```

Проверяется: файл существует, разрешение и 16:9, кадры в секунду, кодеки, длительность 60 с ± 0,5, есть ли звук и не тишина ли, нет ли перегрузки, целиком ли декодируется файл. Код выхода 0 = всё в порядке.
Каждая сборка сама запускает эту проверку и пишет отчёт в `reports/latest_report.md`, а подробный лог — в `reports/build_log_*.txt`.

## Что где лежит

| Папка / файл | Назначение |
|---|---|
| `characters/<имя>/character.yaml` | Персонаж: цвета, рост, форма ушей. Один раз описан — используется во всех сериях |
| `episodes/episode_001/episode.yaml` | Сценарий серии: сцены, движение, звуковые эффекты, титры |
| `scripts/bos_render.py` | Отрисовка кукол, фонов, шарика |
| `scripts/bos_audio.py` | Музыка и эффекты, создаются формулами (оригинальные, без лицензий) |
| `scripts/build_episode.py` | Сборка серии |
| `scripts/verify_video.py` | Проверка MP4 |
| `assets/backgrounds/` | Фоны (создаются автоматически, можно заменить своими PNG 1920×1080 с тем же именем) |
| `renders/` | Готовые видео (в git не хранятся, пересобираются) |
| `reports/` | Отчёты и логи |

## Новая серия

1. Скопировать `episodes/episode_001` в `episodes/episode_002` и поменять `id`, сцены, движения.
2. `python3 scripts/build_episode.py episodes/episode_002`.

Новый персонаж: папка `characters/<имя>/character.yaml` по образцу Бонни или Оли и его имя в списке `characters` серии.

## Что автоматически, а что вручную

- Автоматически: отрисовка, музыка, эффекты, сборка MP4, проверка файла, отчёт.
- Вручную: написать сценарий серии, посмотреть и послушать результат, решить, публиковать ли.
- Публикации в проекте нет и не будет без вашей отдельной команды.

## Честные ограничения

- Это простая 2D-«кукольная» анимация из плоских фигур, а не студийная 3D. Blender не использовался.
- Озвучки голосом нет: серия «без слов» (музыка, эффекты, пантомима). Для голоса положите свою запись в `assets/audio/`; подключение дорожки в сборку пока не реализовано.
- Автоматическая проверка не оценивает красоту картинки и приятность звука — это нужно смотреть и слушать самому.
