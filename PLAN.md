## 2. Выбор способа производства
**Основной (шаг 1, ничего не ставим): 2D-«кукольная» анимация на Python + FFmpeg.**
Персонажи собираются из частей (тело, голова, руки, ноги, глаза) как картонные куклы; код двигает, поворачивает и масштабирует части по ключевым кадрам, кадры рисуются Pillow, потом FFmpeg собирает MP4.
- Плюсы: бесплатно, работает на этой машине сразу, быстро, воспроизводимо, персонажи переиспользуются.
- Минусы: это простая 2D-анимация в стиле детского «кукольного» мультика, НЕ студийная 3D. Качество рисунка зависит от того, как мы нарисуем части (сначала — простые векторные формы, позже можно подставить ваши рисунки).

**Опциональный (шаг 2, только с вашего подтверждения): Blender в режиме без окна.**
- Бесплатный, 3D. Но на машине нет GPU: рендер идёт на CPU (Eevee требует GPU/OpenGL, поэтому пришлось бы использовать Cycles на CPU — медленно, либо Workbench — некрасиво). 60 секунд × 24 к/с = 1440 кадров; это часы рендера.
- Решение: сначала сделать 1 тестовую сцену и измерить время/качество, и только потом решать. Никаких обещаний заранее.

## 3. Звук (всё бесплатно и оригинально)
- **Музыка**: синтезируется кодом (numpy → WAV): простая мелодия и аккомпанемент, оригинальная, без лицензий.
- **Эффекты** (шаги, «боинг», свист): синтез кодом.
- **Озвучка**: бесплатного качественного русского голоса в машине сейчас нет. Варианты:
  1. Без слов (пантомима + музыка + эффекты + короткие надписи) — работает сразу. **Рекомендую для серии 1.**
  2. Установить `espeak-ng` (бесплатно, офлайн, но голос роботизированный) — потребует вашего подтверждения.
  3. Записать голос самим и положить файл в assets/audio/ — лучшее качество.
  Платные нейро-голоса (ElevenLabs и др.) не используются.

## 4. Серия 1 (60 с, 16:9, 1920×1080, 24 к/с)
Сюжет-заготовка (оригинальная, без слов): Бонни находит воздушный шарик, Оли пытается его поймать, шарик улетает, друзья смеются.
Сцены: (1) двор, знакомство 0–12 с; (2) находка шарика 12–27 с; (3) погоня 27–45 с; (4) шарик улетает, финал 45–60 с.
Файл: episodes/episode_001/episode.yaml (сцены, тайминги, действия).

## 5. Обязательные требования — как будут выполнены
| Требование | Реализация |
|---|---|
| Переиспользование персонажей | characters/<имя>/character.yaml; серии ссылаются по имени |
| Проверка MP4 | scripts/verify_video.py: ffprobe — длительность 60±0.5 с, 1920×1080, есть аудиодорожка, файл декодируется без ошибок |
| Исходники и пересборка | всё в yaml + код в git; renders/ пересобирается одной командой |
| Логи и отчёт | reports/build_log_*.txt и reports/report_*.md (ok/fail, причины) |
| Без публикации | в проекте нет кода публикации; публикация — только по отдельной просьбе |

## 6. Этапы реализации (после вашего подтверждения)
1. Движок отрисовки: 1 персонаж, 1 фон, 2 с видео без звука → проверка.
2. Бонни + Оли, анимации (идти, прыгать, махать, смеяться) → проверка.
3. Все 4 сцены без звука, 60 с → проверка длительности/разрешения.
4. Синтез музыки и эффектов, сведение → проверка наличия аудио.
5. Единая команда сборки, verify_video.py, отчёт и логи.
6. Честная оценка результата в reports/ (что получилось, что нет).

Что требует вашего участия: подтверждение каждого этапа, оценка внешнего вида персонажей, решение по озвучке и Blender.
Что полностью автоматически: отрисовка, звук, сборка, проверка, отчёт.
