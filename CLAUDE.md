# BonnieAndOllieStudio — постоянные правила проекта

Локальная бесплатная студия мультсериала «Бонни и Оли». Пользователь — новичок: каждый шаг объяснять простыми словами.

## Жёсткие правила
1. Бесплатно: никаких платных API, подписок, кредитов. Если функция платная — прямо сказать и предложить альтернативу.
2. Ничего не устанавливать, не удалять и не менять системные настройки без отдельного подтверждения пользователя.
3. НИЧЕГО не публиковать (YouTube, соцсети, push в публичные места) без отдельного подтверждения.
4. Секреты (ключи, токены, пароли) не показывать и не записывать в файлы и логи.
5. Не обещать качество студийной 3D-анимации, пока оно не проверено на реальном рендере. Фиксировать фактический результат в reports/.
6. Не заявлять «готово», пока результат не проверен `scripts/verify_video.py` (длительность, разрешение, звук, целостность).
7. Только оригинальный контент: музыка и звуки синтезируются самим проектом, фоны рисуются кодом. Чужие материалы — только с проверенной свободной лицензией и записью об источнике.

## Структура
- characters/<имя>/ — character.yaml (описание, цвета, размеры частей) и эталонные изображения. Переиспользуются во всех сериях.
- episodes/episode_NNN/ — episode.yaml (сцены, тайминги, действия), исходники серии.
- scripts/ — инструменты сборки и проверки.
- assets/backgrounds/, assets/audio/ — фоны, звук.
- renders/ — готовые MP4 (не в git, пересобираются).
- reports/ — отчёты проверки и логи ошибок.

## Принципы сборки
- Одна команда собирает серию из исходников: `python3 scripts/build_episode.py episodes/episode_001` (`--preview 6` — быстрая проба). Проверка файла: `python3 scripts/verify_video.py renders/episode_001.mp4`.
- Метод: 2D-«кукольная» анимация (Pillow + numpy + ffmpeg); звук синтезируется кодом. Blender пока не используется.
- Исходники (yaml, код) хранятся в git; рендеры воспроизводимы из них (фиксированный seed).
- Персонажи не копируются в серии, а подключаются по имени из characters/.
- Каждая сборка пишет лог в reports/ и итоговый отчёт (ok/fail + причины).
